## 🚀 Running Locally

Want to inspect the magic or tweak the code? Run it locally in less than 60 seconds:

```bash
# 1. Clone the repository
git clone https://github.com/KIRATH25/Portfolio.git

# 2. Navigate to the project directory
cd Portfolio

# 3. Install dependencies
npm install

# 4. Fire up the Vite local dev server
npm run dev
```

Open your browser and navigate to `http://localhost:5173`. ⚡

---

## 🛠️ Build for Production

To generate the optimized static production bundle:

```bash
npm run build
```

Preview the production build locally:

```bash
npm run preview
```
